# 💰 MoneyNest - Expense Tracker App

MoneyNest is a simple, intuitive, and privacy-focused personal expense tracker application built using **Kotlin** and **Jetpack Compose** for Android. The app helps users keep track of their income, expenses, budgets, and spending patterns in a clean and user-friendly interface.

---

## 🚀 Features

- 📊 **Track Income & Expenses**: Log transactions easily with categories, amounts, and dates.
- 🏷️ **Manage Categories**: Add, edit, and delete income or expense categories.
- 📅 **Budget Planner**: Set monthly budgets for each category and visualize spending progress.
- 📈 **Analytics Screen**: Visual pie charts for income and expenses to help users understand spending patterns.
- 🌐 **Multi-Currency Support**: Choose from multiple currencies with search functionality.
- 🌙 **Dark & Light Mode**: Seamlessly switch between themes based on user preference.
- 🔔 **Notifications**: Receive reminders to log daily expenses.

---

## 🛠 Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Room Database**
- **StateFlow & LiveData**
- **WorkManager (for scheduled notifications)**
- **Material Design 3**

---

## 📱 Screens

1. **Main Screen**: Add income or expense transactions.
2. **Budget Planner Screen**: Set category limits and view spending.
3. **Analytics Screen**: Visualize data using charts.
4. **Category Management Screen**: Organize transaction categories.
5. **Settings Screen**: Manage preferences, security, appearance, and currency.

---

## 🌍 Target Audience

MoneyNest is designed for individuals who want an easy-to-use and privacy-respecting app to manage daily expenses and budgets without unnecessary complexity. It’s ideal for working professionals, students, and anyone looking to build better financial habits.
